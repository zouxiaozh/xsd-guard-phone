# 学时兑守护 · 手机端

> **永久免费使用**：无广告、无内购、无需注册、无需 Root。

一个装在手机上的通用 ADB 守护工具：可添加任意 App 作为守护任务，完成远程安装、权限补齐、进程拉起与被删重装。默认预置「学时兑」任务，老用户升级后配置与行为保持不变。不用开电脑，在手机上点几下就能完成。

## 功能

- **通用任务**：可添加任意包名，每个任务独立开关「自动补装 / 自动授权 / 自动拉起」
- **两种安装包来源（任选）**：固定下载网址（联网下载后推送），或从手机本地选择 APK 推送
- **查询电视应用包名**：连上 ADB 后一键列出电视里所有第三方应用包名，点包名即可复制到剪贴板，粘贴到任务包名输入框——不知道目标 App 包名时特别好用
- **权限一键补齐**：悬浮窗、电池白名单、开机自启、防休眠，开完还会逐项复核
- **被删自动装回**：检测到任务 App 被卸载，按任务配置的来源取包、安装并唤醒
- **进程保活**：目标 App 进程被杀后自动拉起；守护服务被系统清掉后也会自恢复
- **掉线重连**：每 10 秒检测一次 ADB 连接，异常自动恢复，失败按指数退避冷却
- 无需 Root，安卓 5.0+，免费无广告

## 安装（直接装现成 APK）

`apk/XsdGuardPhone-v3.7.apk` 是最新版已签名安装包（旧版 `v3.6`、`v3.5`、`v3.4`、`v3.3`、`v3.2`、`v3.1`、`v3.0`、`v2.14.3` 也保留在 `apk/`）。

1. 把 APK 传到手机，点击安装；需在系统设置里允许「未知来源」安装
2. 在「设备列表」填电视的局域网 IP:端口（默认 `192.168.31.9:5555`），电视需开启网络 ADB 调试，手机与电视同局域网
3. 点「连接 ADB」，电视弹出调试授权时勾选「始终允许」并确认
4. **不知道包名**：连接成功后点「查询电视应用包名」，列表里点包名右侧「复制」，再粘贴到下一步的包名输入框
5. 在「守护任务」填名称、包名（默认已预置「学时兑」，可不用改）；安装包来源二选一：填固定下载网址，或点「选择本地 APK」从手机里挑一个安装包（授权长期保留）
6. 点「安装任务到电视」完成安装（装完自动授权），再点「启动守护」即可

每个任务都能单独编辑、停用或删除；默认任务的自动补装 / 授权 / 拉起全部开启，老配置升级后继续生效。安装与授权已统一到全局按钮，任务卡片不再单独放这两个按钮。

> 提示：卸载重装守护 App 会生成新的 ADB 密钥，需要在电视上重新授权一次。覆盖安装（`adb install -r`）则不会。

## 构建

```bash
cd tools
python build_phone_guard.py
```

构建脚本用 aapt2 编译资源与清单，ECJ 编译 Java，d8 生成 dex，zipalign 对齐后用 apksigner 签名。

完整构建还需要以下**未随仓库分发**的依赖：

- `sig-tools/`：JDK 17、Android SDK 14 的 aapt2 / d8 / apksigner / zipalign
- `toolchain/`：编译用 stub jar
- `framework-tv.jar`：精简版 framework 资源，用于生成 TV 桌面横幅（缺失时仍可出包，只是没有横幅）
- `xsdanser-custom.keystore`：签名密钥（请用自己的密钥替换，勿提交）

## ADB 实现说明

ADB 协议在 `AdbClient.java` / `AdbProtocol.java` / `AdbCrypto.java` 中从零实现，不依赖第三方库。密钥对在设备首次授权时生成并保存在应用私有目录。

注意：ADB 密钥与设备授权一一绑定。卸载重装守护 App 会生成新密钥，需要在电视上重新授权。
